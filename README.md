## Sobre

O **King's Newsletter** é um ecossistema de informação feito no Brasil, para brasileiros. Reunimos as notícias que importam e explicamos o que está por trás delas, com linguagem clara, dados verificáveis e compromisso com a imparcialidade.

## Ecossistema

| Projeto | O que é | Destaques |
| :--- | :--- | :--- |
| **King's Newsletter** | Resumo diário das principais notícias do Brasil e do mundo | Edições diárias · Arquivo pesquisável · Envio por e-mail |
| **King's Economy** | Economia brasileira explicada do zero | Indicadores ao vivo · Conceitos sem jargão · Contexto histórico |
| **King's Sports** | Cobertura esportiva completa | Jogos do dia · Placar ao vivo · Tabelas e fichas |

## Princípios editoriais

Todo conteúdo publicado segue três compromissos:

1. **Clareza sobre a natureza da informação.** Cada informação é identificada pelo que ela é:

   | Tipo | Significado |
   | :--- | :--- |
   | **Fato** | Acontecimento confirmado e verificável |
   | **Declaração** | O que alguém afirmou, atribuído a quem disse |
   | **Proposta** | Algo sugerido ou em discussão, ainda não aprovado |
   | **Rumor** | Informação não confirmada, sinalizada como tal |
   | **Análise** | Interpretação e contexto, separados dos fatos |

2. **Fontes oficiais em primeiro lugar.** Priorizamos órgãos públicos, documentos e dados primários.
3. **Imparcialidade.** Não induzimos posição política nem favorecemos candidatos ou partidos.
